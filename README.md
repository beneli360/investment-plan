# תכנית השקעה — מיליון שקל

שני נכסים עצמאיים בעברית (RTL), כל אחד קובץ HTML יחיד ללא תלויות ובלי שלב build.
נפתחים ישירות בדפדפן, בנויים mobile-first.

| קובץ | מה זה |
|---|---|
| [`deck.html`](deck.html) | מצגת של 18 שקופיות בעברית פשוטה — לצפייה והצגה |
| [`investment-plan.html`](investment-plan.html) | דשבורד אינטראקטיבי עם סימולטור צמיחה, צ׳קליסט ביצוע ועקרונות |

## התיק

| רכיב | סכום | משקל | תשואה שנתית מונחת |

| מדד S&P 500 | 500,000 ₪ | 50% | 8.5% |
| נאסד״ק 100 | 200,000 ₪ | 20% | 11.0% |

| **סה״כ** | **1,000,000 ₪** | **100%** | **8.55%** |

צפי לעשר שנים: כ-2,299,000 ₪ (פי 2.30). אחרי אינפלציה ומס רווחי הון: כ-1,597,000 ₪ בערכי היום.

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז `http://localhost:8000/deck.html`. לצפייה בטלפון באותה רשת, החליפו את `localhost`
בכתובת ה-IP המקומית של המחשב.

## סטטוס

`deck.html` מעודכן לתמהיל ארבעת הרכיבים. `investment-plan.html` עדיין מציג את
התמהיל הקודם בן שלושת הרכיבים (650/250/100) וטרם סונכרן.
