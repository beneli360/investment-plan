# תכנית השקעה — מיליון שקל

מצגת אינטראקטיבית אחת בעברית (RTL) — קובץ HTML יחיד ללא תלויות ובלי שלב build.
נפתחת ישירות בדפדפן, בנויה mobile-first, עם מצב כהה/בהיר.

[`deck.html`](deck.html) נפתח במסך בחירת מסלול, וממנו נכנסים לאחת משתי מצגות מלאות:

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז `http://localhost:8000/deck.html`. לצפייה בטלפון באותה רשת, החליפו את `localhost`
בכתובת ה-IP המקומית של המחשב.
